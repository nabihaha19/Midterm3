# Project Title: Two-Page Website

## Description
This project is a simple two-page website consisting of a login/sign-up page and a landing page. The website is styled using Bootstrap and includes custom CSS for additional styling.

## Files Overview
- **index.html**: The login/sign-up page with forms for user authentication.
- **landing.html**: The landing page displayed after successful login, featuring welcome messages and navigation links.
- **css/ash.css**: Custom styles to enhance the appearance of the website beyond Bootstrap's default styles.
- **js/script.js**: JavaScript file for interactive features, including form validation and dynamic content updates.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the project folder in your preferred code editor.
3. Open `index.html` in a web browser to view the login/sign-up page.
4. Use the navigation to access the landing page after logging in.

## Features
- User authentication with login and sign-up forms.
- Responsive design using Bootstrap.
- Custom styling for a unique look and feel.
- Interactive elements powered by JavaScript.
